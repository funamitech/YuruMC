How to play

This server is playable on both Java Edition and Bedrock Edition. Use mc.funami.tech as the server address — no port needed on either edition.

YuruMC — semi-vanilla SMP

The main server. Survival, minimal rules.

  • Java Edition mc.funami.tech
  • Bedrock Edition mc.funami.tech port 19132 (default)
Bedrock players join through Geyser Live map (BlueMap)
  1. 1

    Open Multiplayer

    In Minecraft, go to Multiplayer (Java) or Servers (Bedrock) and add a server.

  2. 2

    Enter the address

    Type mc.funami.tech. Leave the port alone.

  3. 3

    Join and have fun

    Read the two rules below and you're set. Enjoy!

Rules

We have just two rules. Everything else is up to you. Even hacked clients are allowed!

  1. 1

    Don't lag the server.

    This includes lag machines and *ban techniques.

  2. 2

    Don't grief.

    You can do anything you want, except griefing or lagging the server.
