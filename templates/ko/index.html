YuruMC 세미 바닐라 SMP

규칙 두 개, Java와 베드락, 지친 유이 한 명.

  • Java 에디션 mc.funami.tech 포트 필요 없어요, 진짜예요
  • 베드락 에디션 mc.funami.tech 포트 19132 (기본값, 그대로 두세요)
Java 마인크래프트 26.2, ViaVersion 없음, 버전 맞춰주세요 베드락 유저는 Geyser로 접속 BlueMap 구경하기
  1. 1

    멀티플레이 열기

    마인크래프트에서 멀티플레이(Java) 또는 서버(베드락)로 들어가서 서버를 추가하세요. 다들 해본 적 있죠?

  2. 2

    주소 입력

    mc.funami.tech를 입력하세요. Java 에디션은 이것만 하면 돼요. 베드락 유저는 포트를 19132 그대로 두세요.

  3. 3

    접속해서 즐기기

    아래 규칙 두 개를 읽으면(네, 둘 다요) 준비 끝이에요. 재밌게 즐기세요!

규칙 (딱 두 개예요)

나머지는 전부 자유예요. 핵 클라이언트도 허용! 네, 진짜예요.

  1. 1

    서버에 렉 걸리게 하지 마세요.

    렉 머신이나 *밴 기술 같은 것도 다 포함이에요. 학생이 집에서 돌리는 서버거든요. 유이는 책상에서 팬 돌아가는 소리를 다 들을 수 있답니다.

  2. 2

    테러하지 마세요.

    테러랑 렉 유발만 빼면 뭘 해도 괜찮아요! 못생긴 집을 짓는 건 합법이에요. 남의 집 위에 짓는 건 안 돼요. 유이는 기억력이 아주 좋거든요.
