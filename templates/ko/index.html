How to play

Yui will explain this exactly once. Use mc.funami.tech as the server address. Java needs no port. Bedrock's port field comes pre-filled with 19132; leave it. That's the whole tutorial.

YuruMC semi-vanilla SMP

Two rules, Java and Bedrock, one tired Yui.

  • Java Edition mc.funami.tech no port, we promise
  • Bedrock Edition mc.funami.tech port 19132 (the default, leave it alone)
Minecraft 26.2 on Java, no ViaVersion, so match it Bedrock players sneak in through Geyser BlueMap, go peek
  1. 1

    Open Multiplayer

    In Minecraft, go to Multiplayer (Java) or Servers (Bedrock) and add a server. You've done this before.

  2. 2

    Enter the address

    Type mc.funami.tech. Java needs nothing else. Bedrock players, leave the port at 19132.

  3. 3

    Join and have fun

    Read the two rules below (yes, both) and you're set. Enjoy!

Rules (there are two)

Everything else is up to you. Even hacked clients are allowed! Yes, really.

  1. 1

    Don't lag the server.

    This includes lag machines and *ban techniques. It's a student's home server. Yui can hear the fans from her desk.

  2. 2

    Don't grief.

    You can do anything you want, except griefing or lagging the server! Building an ugly house is legal. Building it on top of someone else's house is not. Yui has a very long memory.

That's the whole rulebook.
